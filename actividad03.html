1. Flujo del Paquete

Cuando un paquete llega al sistema, sigue el siguiente orden jerárquico:

1. TABLA   ->   2. CADENA   ->   3. ACCIÓN

2. Tablas y Propósitos

Tabla Propósito Principal Ejemplo de Uso
FILTER Filtrar paquetes Accesos en tráfico de red
NAT Traducción de direcciones Modificar las IP
MANGLE Modificación de paquetes Colocar marcas a los cabezales
RAW Excepciones de conexiones Paquetes sin ser inspeccionados
SECURITY Aplicar etiquetas de seguridad Políticas de seguridad (SELinux)

3. Anatomía y Análisis de Comandos

Comando Básico

iptables -A INPUT -p tcp -m multiport --dports 80,443 -j ACCEPT

Interpretación: Permite el tráfico TCP entrante hacia los puertos de destino 80 y 443.

Variables y Opciones Comunes

# a) Limitar intentos por minuto
iptables -m limit --limit 5/minute

# b) Filtrar por IP de origen
iptables -s 192.168.1.0/24

# c) Ver solo números (sin DNS)
iptables -L -n

# d) Ver reglas con contadores
iptables -L -v

Análisis de Regla Compuesta

iptables -A INPUT -i eth0 -p tcp -m multiport --dports 22,80,443 -m state --state NEW,ESTABLISHED -j ACCEPT

Explicación: Permite tráfico TCP entrante por la interfaz eth0 a los puertos 22, 80 y 443, solo si la conexión es nueva o establecida.

4. Traducción de Reglas (Ejercicios)

7. Permitir tráfico HTTP entrante

iptables -A INPUT -p tcp --dport 80 -j ACCEPT

8. Permitir todo el tráfico saliente

iptables -A OUTPUT -j ACCEPT

9. Permitir SSH solo desde la IP 192.168.1.50

iptables -A INPUT -p tcp --dport 22 -s 192.168.1.50 -j ACCEPT

10. Permitir tráfico TCP entrante a puertos 80 y 443 (Establecidas)

iptables -A INPUT -p tcp -m multiport --dports 80,443 -m state --state ESTABLISHED,RELATED -j ACCEPT

11. Registrar intentos y luego permitir

# Primero: Registrar (LOG) iptables -A INPUT -i eth0 -p tcp -m multiport --dports 22,80,443 -m state --state NEW,ESTABLISHED -j LOG --log-prefix "Intento: " # Segundo: Aceptar (ACCEPT) iptables -A INPUT -i eth0 -p tcp -m multiport --dports 22,80,443 -m state --state NEW,ESTABLISHED -j ACCEPT
